# 전자책 조달과 권리 전략

조사 기준: 2026-09-15, 제품 적용: 2026-09-16. 아래는 공식 자료를 바탕으로 한 개발 의사결정이며, 개별 작품·계약의 법률 검토를 대신하지 않는다.

## 결론

초기에는 **각자 확보한 책으로 참여하는 커뮤니티 + 권리가 확인된 콘텐츠의 앱 내 읽기**를 병행한다. 도서 검색 API는 발견을 돕고, 원문을 제공할 권리는 별도로 확보한다. 최신 상용 전자책을 앱 안에서 읽게 하는 것이 필수라면 출판사·전자책 유통사와 공급/이용권 계약 논의가 지금부터 필요하다.

## 조달 방식 비교

| 방식 | 얻는 것 | 얻지 못하는 것 / 확인 조건 | 판단 |
|---|---|---|---|
| Kakao 책 검색 | 제목·ISBN·저자·번역자·표지 URL·상품 URL | EPUB 원문/구매자 열람권 제공 API가 아님. 키 관리·캐시·표지 표시 조건 별도 확인 | 국내 메타데이터 후보 |
| Google Books API | 서지, 국가별 열람 가능성, 미리보기/임베드 가능 여부 | 모든 책의 본문·공동 열람·재배포 권한이 생기지 않음 | 보조 검색·허용된 미리보기 후보 |
| 외부 서점 링크 | 독자가 원래 서점에서 구매/열람 | 구매가 자동으로 우리 리더의 라이선스가 되지 않음; 영수증만으로 복호화 불가 | 책 확보 안내용, 모바일 결제 정책 검토 후 |
| 구매 페이지 WebView/iframe | 표시가 허용된 경우 외부 페이지 | 서점 허가·쿠키/로그인·프레이밍·스토어 심사 문제, 원문 권리 미해결 | MVP에서 제외 |
| 공유마당의 만료/기증/CC 자료 | 허용 범위가 확인된 원문 | 원작/번역/삽화/판본 각각 확인. 모든 무료 자료가 상업적 재배포 가능하지 않음 | 한국어 파일럿 우선 |
| Project Gutenberg 등 | 영문 고전·EPUB 조달 후보 | 미국 판단을 한국/전세계에 그대로 적용 불가, 개별 라이선스·상표·수집 규칙 확인 | 작품별 심사 후 |
| 작가·독립출판사 직접 허락 | 작은 카탈로그로도 한국어 내장 읽기 가능 | 공중송신·기간·지역·동시 이용자·인용·오프라인·정산 합의 | 가장 현실적인 제휴 실험 |
| 이용자 개인 EPUB 가져오기 | 본인 기기의 DRM-free 파일 읽기 | 업로드/모임 자동 배포 권리가 아님, 악성 EPUB 격리·보관 정책 필요 | 엔진 검증 뒤 로컬 한정 고려 |
| 도서관/기관 B2B | 계약된 이용자에게 대여 가능성 | 기존 도서관 이용권을 일반 서비스에 전용할 수 없음 | 별도 기관/공급사 계약 경로 |

Kakao 응답의 `contents`는 도서 소개이고 본문이 아니다. [공식 책 검색 API](https://developers.kakao.com/docs/ko/daum-search/dev-guide#search-book)

Google Books의 `accessInfo`에는 `country`, `viewability`, `embeddable`, `publicDomain` 등이 있다. 허용 여부를 개별 도서·이용 지역 기준으로 확인하고, 허용된 뷰어 기능만 사용한다. 실제 앱 WebView 호환·한국어 카탈로그의 활용도는 추가 실험이 필요하다. [Volume API](https://developers.google.com/books/docs/v1/reference/volumes), [Embedded Viewer](https://developers.google.com/books/docs/viewer/developers_guide)

**알라딘 신규 의존 제외:** 공식 고객센터 공지 목록에서 “OpenAPI 서비스 종료 안내(26.10.30)”를 확인했다. 공지 상세의 대체 계약·이행 조건은 이번 조사에서 확인하지 못했다. 기존 알라딘 기반 OSS의 API 호출을 그대로 채택하지 않는다. [공식 고객센터](https://ttb.aladin.co.kr/cs_center/wcs_main.aspx)

## 수기 타이핑과 고전의 주의점

수기 입력·OCR·재편집은 입력 방법일 뿐이다. 권리 있는 작품의 본문을 서버에 저장해 다수에게 제공하는 서비스가 사적 이용 예외에 해당한다고 가정할 수 없다. 원작이 만료되었어도 현대 번역·삽화 등은 별도 보호될 수 있다. 저작권법 제5조·제16조·제18조·제30조·제39조·제46조와 개별 작품에 적용되는 경과 규정 등을 확인해야 한다. 사망연도+70만으로 모든 판본·지역을 일괄 승인하지 않는다. [현행 저작권법](https://www.law.go.kr/LSW/lsInfoP.do?lsId=000798), [사적 이용 조문](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1025202705)

실행 가능한 대안은 한국어 만료 원문을 검수해 전자화하거나, 만료 원작의 새 번역을 직접 제작·의뢰하면서 이용 조건을 정하는 것이다. 공유마당도 개별 항목의 조건을 기록해야 한다. [공유마당 만료저작물](https://gongu.copyright.or.kr/gongu/main/contents.do?menuNo=200091)

Project Gutenberg는 미국 중심의 권리 판단을 명시하며, 미국 밖에서 재배포할 때는 해당 국가 법률 확인을 요구한다. 파일럿에서도 원문·번역·판본·서비스 지역을 묶어 판단한다. [권한 안내](https://www.gutenberg.org/policy/permission)

## 모바일 구매 정책

전자책을 앱에서 소비하도록 판매하는 기능과 실물 책 구매는 다르게 다뤄진다. Apple의 reader-app 계정 링크 자격은 자동으로 부여되지 않으며, 소셜 기능이 주가 되는 서비스가 같은 자격을 받는다고 단정할 수 없다. reader entitlement는 일반적인 서점 checkout 임베드 허가가 아니다. 스토어·지역·앱 기능·참여 프로그램별로 확인한다. [App Review 3.1](https://developer.apple.com/app-store/review/guidelines/), [Reader apps](https://developer.apple.com/support/reader-apps/)

Google Play도 앱 내 디지털 콘텐츠 결제에 관한 기본 정책과 지역/프로그램 예외가 있다. 한국 서비스라는 이유만으로 WebView 외부 결제를 자유롭게 넣지 않는다. 출시 시점 공식 정책과 필요한 등록을 다시 확인한다. 초기 프로토타입에는 결제·판매 링크를 넣지 않는다. [Google Play 결제 정책](https://support.google.com/googleplay/android-developer/answer/9858738)

## 콘텐츠 입고 규칙 — 실서비스 설계

작품별이 아니라 **판본별 rights record**를 관리한다.

필수값: work ID, edition ID, 언어/번역자, 권리자, 근거 URL/계약 ID, 허용 지역, 시작/만료일, 열람·다운로드·오프라인·인용/주석·TTS 허용 범위, 동시접속 조건, DRM 조건, 파일 해시, 검토자/검토일.

상태: `pending → approved → suspended/expired`. 불명확한 자료는 pending이다. 서비스 기본값은 비공개이며, approved이고 지역·기간·개별 열람권이 모두 유효할 때만 원문을 전달한다. 앱/서버 데이터 변경은 권리 승인과 구분한다. 서지 노출 가능 여부도 별도 관리한다.

계약 만료 시 새 다운로드를 중단하고, 오프라인 파일의 잔여 이용·폐기는 계약과 기술 구조에 따라 처리한다. DRM이 없는 파일은 이미 복사된 것을 완전히 회수할 수 없으므로 회수 가능하다고 약속하지 않는다. 원문 파일은 채팅/Presence payload로 보내지 않는다.

## 추천 파일럿

1. 데모: 이번 작업에서 새로 쓴 샘플 글만 사용.
2. 검증용 공개 콘텐츠: 한국어 원문 3~5편을 판본·권리까지 확인해 큐레이션. 아직 승인된 목록은 없음.
3. 제휴: 독립출판사/작가 1곳과 짧은 작품의 제한된 기간·인원 파일럿 제안.
4. 모임 참여/읽기 유지 효과가 확인되면 카탈로그와 DRM에 투자.

제휴 조건과 보내기 전 초안은 [PARTNERSHIP.md](PARTNERSHIP.md)에 정리했다. 실제 연락은 아직 하지 않았다.
