# 여백 — 제품 방향과 개발 범위

결정일: 2026-09-16. **여백은 임시 작업명**이며 상표·스토어 이름 사용 가능 여부는 미확인이다.

## 핵심 가치

**같은 책을 각자의 속도로 읽고, 내가 읽은 지점에서 다른 독자를 만난다.**

대상은 iOS·Android를 쓰는 한국어 일반 독자. 처음부터 책방 운영자용 관리 도구나 소셜 피드 전체를 만들지 않는다. 종이책·외부 전자책 독자도 모임에 참여할 수 있고, 권리 확보 콘텐츠에서는 본문과 대화가 연결된다. 광안리 책방의 감각은 차분한 화면·조명 같은 강조색·읽기에 집중하는 밀도로 표현한다.

## 조사에서 가져올 원칙

| 참고 | 관찰된 강점 | 여백에 적용 | 새로 설계할 부분 |
|---|---|---|---|
| Fable | 장별 토론과 본문 반응 | 책→장→감상 맥락 유지 | 실시간 대화가 본문을 가리지 않는 접히는 여백 |
| StoryGraph | 진도에 따른 반응 가림 | 읽기 전 감상을 먼저 노출하지 않기 | 판본별 위치를 구분하고 장 단위 안전한 공개 |
| Bookclubs | 일정·투표·모임 운영 | 모임의 목표와 다음 읽을 구간을 분명히 | 초기에는 일정 하나와 읽을 구간 하나만 |
| 그믐 | 책 중심으로 모이는 대화 | 책을 보고 모임에 들어가는 구조 | 모바일 한 손 동선과 조용한 개인 기록 |
| 밀리·리디 | 서재·이어읽기·독서노트 | 읽다가 돌아와도 이어지는 개인 경험 | 커뮤니티와 원문 열람 권한 분리 |

세부 근거·확인 범위는 [서비스 조사](research/service-references.md). 로그인 뒤 미관찰 화면은 추정하지 않았다. 기능 원칙을 참고하며 화면·문구·그래픽은 복제하지 않는다.

## 실시간의 정의

실서비스의 실시간 기능은 방 멤버의 접속 상태, 동의한 진도 공유, 새 감상 알림이다. 다른 사람의 페이지를 강제로 넘기거나 전자책 파일을 방송하지 않는다. 사용자는 혼자 읽기를 유지하고 대화를 열 때 참여한다. 페이지 동기화는 진행자가 있는 별도 세션을 검증한 뒤 선택 기능으로 고려한다.

## 초기 사용자 여정

1. 책이나 읽고 싶은 분위기로 모임을 찾는다.
2. 읽을 수 있는 방법을 확인한다: 내 책으로 참여 / 앱 안에서 읽기 가능.
3. 참가하고 목표 구간을 정한다. 읽기 속도·진도 공개는 선택한다.
4. 읽은 장을 기록하거나 내장 리더에서 이어 읽는다.
5. 해당 지점까지 공개되는 감상을 보고 자신의 생각을 남긴다.
6. 다음 날 서가의 이어읽기로 돌아온다.

판본이 다르면 같은 페이지 번호로 연결하지 않는다. `work → edition → chapter/locator`를 구분하고, 판본 간 연결은 검증된 장 매핑부터 지원한다.

## 범위와 완료 기준

| 단계 | 구현 범위 | 통과 조건 | 현재 상태 |
|---|---|---|---|
| 0. 경험 검증 | 샘플 서가·모임·3장 리더·진도·북마크·감상, 로컬 저장 | 앱 재실행 후 복원, 읽기 전 감상 가림, 글자 조절·뒤로가기 | 이번 구현 대상 |
| 1. 함께 읽기 베타 | 계정, 방 초대/참여, 차단·신고, 서버 저장, 진도별 대화 | 서로 다른 두 계정/기기에서 권한·재접속·중복 전송 검증 | 미구현 |
| 2. EPUB 읽기 | 권리 확인 자료, 파일/판본 관리, 목차·위치·주석·오프라인 | 한국어 EPUB와 실제 양 플랫폼 기기 품질 통과 | 엔진 비교 필요 |
| 3. 상용 도서 파일럿 | 출판사 계약, 개별 열람권, 정산·DRM·판매 정책 | 계약 범위·지역·만료·스토어 결제 정책 검증 | 사업 협의 필요 |

단계 1과 합법 콘텐츠 파일럿 준비는 병행할 수 있다. 기능이 없는 버튼을 완성품처럼 두거나 로컬 예시를 실제 회원·대화·LIVE 인원처럼 표시하지 않는다.

## 실서비스에서 먼저 필요한 운영 기능

- 공개 모임의 차단·신고·관리자 조치와 이의 제기 경로.
- 계정 삭제 및 개인 기록 내보내기/삭제 정책, 최소 수집 개인정보.
- 장 전체 붙여넣기·반복 인용을 포함한 권리 침해 신고 대응. 짧은 글자수 제한만으로 적법성을 보장하지 않는다.
- 비공개 방 가입 해제 후 API/실시간 채널 접근 차단.
- 스포일러는 피드·알림·푸시 미리보기·검색 결과에도 동일하게 적용.

## 검증할 제품 가설

다음 수치는 성과가 아니라 실험 설계의 예시다. 실제 결과는 별도로 기록한다.

- 5명 사용성 세션: 도움 없이 모임 참가→읽기→감상 작성이 되는지, 막힌 위치를 기록.
- 동기: 책을 이미 가진 독자도 모임에 참여할 이유가 있는가.
- 핵심 지표: 첫 독서+첫 감상까지 도달률, 7일 내 모임 재방문, 읽기 중 이탈, 스포일러 노출 신고.
- 충분한 활동량 전까지 AI 추천·AI 토론 요약·유료 구독을 붙이지 않는다. 초기 운영비와 개인정보 전송을 늘릴 이유가 약하다.

## 우선순위가 낮은 기능

전국 책방 지도, 팔로워 피드, 음성 채팅, 실시간 문서 공동 편집, 모든 서점 구매 연동, 대규모 추천 엔진. 이용자 검증이나 계약이 필요성을 보여 줄 때 추가한다.
