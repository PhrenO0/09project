# 디자인 방향 — 광안리의 밤 책방

## 시각적 명제

검은 서가 사이, 종이 위에 내려앉은 따뜻한 조명과 창밖의 차분한 바다. 검정 위에 화려한 네온이나 해변 사진을 반복하지 않고, 책의 비례·단정한 글자·얇은 구분선으로 만든다.

## 토큰

| 역할 | 값 | 용도 |
|---|---|---|
| Background | `#101311` | 앱 배경 |
| Raised surface | `#1A201C` | 읽고 있는 책·패널 |
| Paper | `#ECE6D8` | 주요 글자 |
| Lamp | `#D4AD75` | 진행·핵심 버튼 |
| Sea | `#82ACA6` | 함께 읽기·상태 보조 |
| Secondary text | `#ADB6AE` | 보조 설명 |
| Rule | `#343D36` | 경계선 |

초기에는 OS 글꼴을 사용한다. 제목은 가능한 명조 계열, 조작/본문은 가독성 우선. 정식 한글 서체는 배포 라이선스 확인 후 추가하며 원문 글꼴과 앱 UI 글꼴을 분리한다.

## 화면 구조

- **서가:** 간결한 브랜드/날짜 대신 고정 서비스 라벨 → 이어읽기 → 책 검색·분류 → 책 목록. 홍보 배너가 첫 행동을 밀어내지 않는다.
- **함께읽기:** 책별 모임, 목표 구간, 참가 상태 → 지금 읽은 장까지의 감상. 실제 서비스에서는 공개/비공개·신고·차단이 필요하다.
- **리더:** 닫기·진도·글자 크기 → 여유 있는 본문 → 장 이동 → 감상. 대화가 책장을 덮지 않는다.
- **내 기록:** 읽은 책·북마크·내 감상. 저장된 기록이 없으면 바로 읽기를 안내.

원하는 인터랙션은 Fable의 책 안 맥락, StoryGraph의 진도 가림, 서점의 큐레이션 밀도를 결합한다. 공간감·표지 그래픽·상태 표현·문구는 새로 구성한다. 기존 서비스 앱을 실제로 조작하지 못한 영역은 [조사 문서](research/service-references.md)에 표시했다.

## 접근성과 상태

- 터치 영역 최소 44pt, 보조 설명도 읽을 수 있는 크기. 색만으로 상태를 전달하지 않는다.
- 글자 확대 시 높이를 고정하지 않고 스크롤/줄바꿈을 허용한다. 읽기 설정은 기기에 저장.
- 로딩·빈 결과·오프라인·저장 실패·참가 해제 상태를 고려한다.
- 스포일러 본문은 숨김 CSS가 아니라 렌더링/서버 응답 경계에서 제외한다. 푸시에도 같은 원칙.
- VoiceOver/TalkBack 순서, 선택 상태, 뒤로가기, 키보드 가림은 실기기에서 별도로 검증한다.
- 바다는 장식적 SVG 선·색의 리듬으로 표현 가능하다. 사용자 본문 가독성보다 우선하지 않는다.

## 현재 프로토타입의 구분

모임/책/감상 샘플은 예시임을 밝힌다. 로그인·실시간 인원·실제 카탈로그를 제공하는 것처럼 보이지 않게 한다. 광안리의 실제 책방과 제휴한 서비스로 표시하지 않는다.
